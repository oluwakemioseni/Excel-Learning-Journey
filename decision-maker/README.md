# Decision Maker

## Overview

Decision Maker is an Excel project designed to help individuals compare multiple career options using a weighted scoring system.

It evaluates job roles against selected criteria and calculates a weighted score to help identify which options best align with an individual's priorities.

## Criteria

The project evaluates job roles based on five criteria:

* **Pay:** The earning potential of the job.
* **Job Market Availability:** The availability of opportunities in the field.
* **Enjoyment:** How much the individual enjoys the work.
* **Existing Skills:** How well the individual's current skills align with the role.
* **Formal Education:** How well the individual's educational background aligns with the role.

Each job is scored on a scale of 1–5.

## Methodology

The project initially used the sum of the individual scores to compare jobs. However, because the criteria have different levels of importance, a weighted scoring approach was introduced.

Each criterion's score is multiplied by its assigned weight, and the resulting values are summed to calculate a weighted total for each job.

Conditional formatting is used to highlight the job with the highest weighted score.

## Excel Skills Applied

* Basic formulas and calculations
* Weighted scoring
* Relative importance of evaluation criteria
* Conditional formatting
* Data-driven decision support

## Purpose

The project demonstrates how Excel can be used to structure a decision-making problem and compare career options systematically.

The results depend on the scores and weights entered and should be used as a guide rather than as a definitive career recommendation.
