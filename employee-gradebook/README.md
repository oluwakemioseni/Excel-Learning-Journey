# Employee Performance Gradebook

## Project Overview

This project is an employee performance gradebook created using Microsoft Excel as part of my Data Analytics learning journey.

The spreadsheet organises employee test results, highlights performance levels, calculates summary statistics, flags scores below a specified threshold, and visualises employee performance using charts.

## Project Objectives

The objectives of this project were to:

* Organise employee information and test results in a structured spreadsheet.
* Use conditional formatting to make performance levels easier to identify.
* Calculate percentage scores and highlight results below 50%.
* Summarise test results using statistical functions.
* Apply logical functions to flag employees who fall below the specified performance threshold.
* Create charts to compare employee test results visually.

## Excel Skills Applied

* **Conditional Formatting:** Applied traffic-light-style colours to test scores and highlighted percentages below 50%.
* **Percentage Calculations:** Calculated employee test scores as percentages.
* **Statistical Functions:** Used `MAX`, `MIN`, and `AVERAGE` to calculate the highest, lowest, and average test scores.
* **Logical Functions:** Used `OR` to flag employees who scored below 50% in any test.
* **Data Visualization:** Created standard Excel charts to compare employee test results.

## Decision Rule

The spreadsheet uses a predefined rule: an employee is flagged if their score is below 50% in at least one test.

This rule demonstrates the use of logical functions in Excel. It is a project-specific assumption, not a recommendation for making real-world employment decisions.
